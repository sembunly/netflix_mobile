# Netflix Clone

A Netflix-inspired iOS app built with **SwiftUI**.

## Requirements

- Xcode 15+
- iOS 17+
- Swift 5.9+

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/sembunly
   ```
2. Open `netflix.xcodeproj` in Xcode.
3. Select a simulator or device and hit **Run** (⌘R).
